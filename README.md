# 🚴 Rennrad Gangschaltungs-Trainer (Shimano 2×11)

Ein interaktiver Web-Simulator zum Erlernen und Trainieren der optimalen Rennrad-Schaltstrategie mit mechanischen Shimano STI-Schalthebeln, 2D-Landschaft mit Höhenprofil und Echtzeit-Bewertung.

![Preview](preview.png)

## ✨ Features
- **Mechanische Shimano STI-Schalthebel**: Realistische Hebel-Animationen und akustisches Klick-Feedback.
- **Kompaktes 2×11 Drivetrain-Modell**: Kompaktkurbel (50/34T) und 11-fach Kassette (11–30T) mit dynamischer Kettenschräglauf-Warnung (Grün/Gelb/Rot).
- **1,6 km Test-Etappe**: Flachstück, 10-Sekunden-Ampelhalt, 8% Brückenrampe, 13.5% Steilanstieg und -9.5% Steilabfahrt.
- **🎓 Pro-Coach Demo-Modus**: Autopilot mit Meisterklasse-Schaltstrategie und anfängergerechten Erklärungen.
- **Fehlerfreie Auswertung**: Detailanalyse mit Trittfrequenz-Zonen, Kettenschräglauf und Rangliste.

## ⌨️ Tastenbelegung
| Taste | Funktion |
|---|---|
| **<kbd>Q</kbd>** | Links: Großes Kettenblatt (50T) |
| **<kbd>A</kbd>** | Links: Kleines Kettenblatt (34T) |
| **<kbd>Ü</kbd>** | Rechts: Gang leichter (größeres Ritzel) |
| **<kbd>Ä</kbd>** | Rechts: Gang schwerer (kleineres Ritzel) |
| **<kbd>Leertaste</kbd>** | Kraft-Modus umschalten (*Leicht* / *Normal* / *Stark*) |
| **<kbd>P</kbd>** | Pause / Weiterfahren |
| **<kbd>R</kbd>** | Runde neu starten |
